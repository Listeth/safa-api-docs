# Quickstart

1. Register at [aisafa.xyz/register](https://aisafa.xyz/register)
2. Create an API key in the dashboard
3. Point your client to `https://aisafa.xyz/v1`

## Cursor

Settings → Models → OpenAI API Key → Base URL: `https://aisafa.xyz/v1`

## Claude Code

```bash
export ANTHROPIC_BASE_URL="https://aisafa.xyz"
export ANTHROPIC_AUTH_TOKEN="your-key"
claude
```
